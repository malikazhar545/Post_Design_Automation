# Post_Design_Automation


Company references: Dashboard > References mein company select/type karein, har line
mein aik full image file path paste karein (maximum 10), phir Save references.
Windows Copy as path ke quotes supported hain. Saved selection agli file se use
hogi aur server restart ke baad bhi rahegi. Use automatic latest 4 se override
remove hota hai; jin companies ke custom paths nahi hain unka existing automatic
selection same hai. Local selections company_references.json mein rehti hain
(Git mein upload nahi hoti). Referenced images apni original location par rakhein.
